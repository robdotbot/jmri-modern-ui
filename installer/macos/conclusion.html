Next steps in JMRI

  1. Preferences → Start Up → Add → Perform action → Start Web Server.
  2. Optional, to let browsers switch track power: Preferences → Web Server, untick Web clients can't change track power.
  3. Restart JMRI.

Then open http://localhost:12080/web/modern/ on this Mac, or http://<this Mac's name or address>:12080/web/modern/ on a phone or tablet. On a phone, "Add to Home Screen" gives a full-screen app.

To remove it later, run in Terminal:
sudo "/Library/Application Support/JMRI Modern UI/uninstall.sh"
