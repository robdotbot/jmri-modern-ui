JMRI Modern UI @VERSION@

A modern, mobile-first web front end for JMRI: throttles, roster, panels, turnouts, signals, operations, programming and logic, on any phone, tablet or computer on your network.

This installs, for the user who is logged in:

  • the app, into ~/Library/Preferences/JMRI/web/modern, which JMRI's web server serves for every profile;
  • the add-on (programming, Logix/LogixNG, panel editing, train building), into the same folder, loaded through jmri.conf.

Nothing inside the JMRI application folder is changed, so upgrading JMRI keeps it.

Quit JMRI (PanelPro, DecoderPro) before continuing.
